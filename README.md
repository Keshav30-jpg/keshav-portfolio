# Build a Modern, Professional Portfolio Website for Keshav S

## 1. Project Overview

Create a fully responsive, modern, clean, and professional personal portfolio website for **Keshav S**, a BCA graduate from Chennai, Tamil Nadu, India, seeking internship opportunities in Data Analytics and AI/ML Engineering.

The website must showcase practical technical skills, real-world projects, educational background, professional development, and a downloadable, viewable resume. The primary objective is to help recruiters and hiring managers quickly understand the candidate's abilities and invite them for internship opportunities.

The design must look polished, distinctive, trustworthy, and suitable for a technically skilled early-career candidate. Avoid generic portfolio templates, excessive decoration, cluttered layouts, and unnecessary visual effects.

## 2. Design System and Visual Identity

### Overall Style
- Use a clean, minimal, contemporary design.
- Use a white or very light neutral background with subtle light-gray section backgrounds.
- Use cyan and electric blue as primary accent colors.
- Use dark navy or charcoal for headings and readable body text.
- Use subtle borders, soft shadows, rounded cards, and generous whitespace.
- Maintain consistent typography, spacing, iconography, and alignment.
- Use a modern font such as Inter, Manrope, or Plus Jakarta Sans.
- Ensure sufficient contrast and accessibility.

### Animations and Interactions
Implement smooth, professional animations without compromising performance:
- Smooth scrolling between sections.
- Subtle fade-in and upward-motion effects when sections enter the viewport.
- Animated project cards with a slight lift and shadow on hover.
- Smooth transitions for buttons, navigation links, and social icons.
- Subtle cyan or electric-blue highlights on interactive elements.
- Animated skill indicators only when they communicate meaningful information.
- Respect the user's reduced-motion accessibility preference.

Avoid excessive parallax, distracting backgrounds, flashy animations, and long loading sequences.

### Responsive Design
The website must work properly on desktop, laptop, tablet, and mobile screens. Use responsive grids, flexible spacing, readable text, and touch-friendly controls.
